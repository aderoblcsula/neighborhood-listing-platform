# Neighborhood Listing Platform



An accessible community platform for discovering local listings, connecting with neighborhood sponsors, and receiving voice-guided help.



## Live Deployment



[View the Neighborhood Listing Platform](https://neighborhood-listing-platform-lake.vercel.app/)



## Features



- Neighborhood listings

- Neighborhood sponsors

- Voice help

- Accessible semantic HTML

- Responsive layout



## Technology Stack



- Next.js App Router

- TypeScript

- Tailwind CSS

- ESLint

- npm

- Vercel
